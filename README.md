# Ydintalvi web map

This is an interactive web map made for the geovisualisation challenge for the course MAAN7771 at the University of Turku.

**[Open the web map](https://vomark.github.io/Ydintalvi-webmap/)**

## About

The interactive web map was built with OpenLayers. You can choose between the RCP 4.5 and
RCP 8.5 climate scenarios, click a statistical area to see the grocery stores
within 200 m and their flood risk class, and view the pending zoning plans.
